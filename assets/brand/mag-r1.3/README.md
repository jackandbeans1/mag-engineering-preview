# MAG identity R1.3 corrected release

Status: approved for the MAG website preview and frozen by repository commit on 2026-08-15.

## Reason for correction

The R1.2 source paths used an A-shaped glyph in the R position of `ENGINEERING` across every full lockup and the social composition. The error was visible in the deployed starter-site preview and invalidates approval of those affected R1.2 files.

## Scope

- Preserve the approved Lane A frame, MAG geometry, colors, spacing, wordmark positions, and documented variant roles.
- Replace only the incorrect glyph path at `translate(244 208)` with a legible block R that fits the existing 35-by-28-unit wordmark cell.
- Preserve LB01 v2 exactly and continue to restrict it to browser-favicon use at 16, 32, and 48 px.
- Preserve the existing MAG website composition. This candidate is integrated into `mag-engineering-preview`; it is not a redesign of the site.

## Required acceptance checks

- `ENGINEERING INC` reads correctly at 244 px, 488 px, and enlarged inspection size.
- The R has a closed bowl, clear diagonal leg, and no collision with the adjacent E or I.
- Primary flat, legacy gradient, one-color black, reversed white, and social lockups use the same corrected R path.
- The real MAG desktop and mobile layouts remain unchanged apart from the identity, favicon, and approved footer-logo references.
